# PSVR2 PR96 integration on 0.1.8

Ported controls and haptics from PR96 head
`06d4b38a7e76f8b15af9e9039b33cd9669a8217a` onto official0.1.8
`9aa2601`, retaining this worktree's existing pacing and diagnostic patches.
This is a source integration, not an upstream PR merge or published release.

* Triangle touch + right stick: D-pad, suppressing look during the entire hold.
* Create tap: Start/Pause; hold500ms: Back/Select.
* Triangle touch + R3: alternate menu gesture; L3+R3 remains the upstream overlay.
* Focus/input-provider loss cancels held menu gestures.
* `SetVRHapticPulse` and the isolated
  `Local\CyberpunkVR_PSVR2_Haptics_017_v1` mapping retain the existing Toolkit
  bridge protocol. No upstream shared input slots are repurposed.
* PSVR2 native shot envelopes are skipped because EDS/Toolkit already provides
  semantic recoil and adaptive triggers. Other native haptic events route to
  Toolkit; no PSVR2 `xrApplyHapticFeedback` calls compete with its PCM output.
  Other headsets retain upstream OpenXR haptics.
* PR96's ordinary-melee pulse envelope is adapted to0.1.8's `ordinary_melee.lua`,
  preserving upstream physical tracking, muting, stroke detection and damage.
  Pulses indicate a swing, not proven NPC contact. Cyberware combat unchanged.

Keep the existing compatible Toolkit driver and017 bridge; the protocol name
does not require the game port itself to remain0.1.7. Start the bridge before
the game. Adaptive trigger profiles, EDS settings and the in-game
Mods > DualSense > PSVR2 Haptics audio menu are external and are not replaced.
Without the bridge, this PSVR2-specific build has no replacement native
OpenXR vibration fallback.

PR96's older FOV implementation is deliberately not applied over0.1.8's
asymmetric projections. Existing FOV settings, pacing, external OFXR,
Cheeky and DLSS are unchanged by this integration.

Validation: input-policy tests (24 checks, GCC and MSVC), Windows shared-memory
channel tests, and Lua physical-melee/cyberware regression tests. In-headset
control and actuator acceptance remains required after deployment.
